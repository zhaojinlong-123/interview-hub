## 逐题解答
### 题目 1：阿里多模态大模型面试中，视觉编码器到 LLM 的连接层如何选型，MLP projector、Q-Former 和 cross-attention adapter 各有什么取舍？

**详细回答：**
这题核心是视觉 token 如何变成语言模型可消费的语义表示。MLP projector 最简单，把 vision encoder 输出线性或非线性映射到 LLM hidden size，延迟低、实现稳，适合 LLaVA 类图文问答和通用多模态 SFT，但它对视觉 token 的筛选能力弱，高分辨率和细粒度任务会把上下文撑得很大。Q-Former 用一组可学习 query 从视觉特征中抽取固定数量的语义 token，能显著压缩视觉输入，适合成本敏感的服务化模型，但容易丢 OCR、小目标和空间细节。Cross-attention adapter 在语言层多次读取视觉特征，交互能力最强，适合复杂推理、grounding 和视频理解，但改造深、推理成本高、训练稳定性要求更高。工程回答要补一句：选型取决于任务粒度、视觉 token 预算、是否冻结 LLM、延迟约束和评测集是否包含 OCR/grounding/空间关系 hard case。

**面试展开：**
如果面试官继续追问，可以把答案落到真实项目：数据从哪里来、如何标注、模型输出什么、低层控制怎么兜底、失败样本如何回流、最终指标如何证明有效。
