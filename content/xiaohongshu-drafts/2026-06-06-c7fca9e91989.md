## 面试题目

1. 视觉 encoder 输出如何对齐到 LLM token 空间，Linear projector、Q-Former 和 cross-attention adapter 有什么取舍？
2. 图文/视频指令微调数据如何构造，如何控制噪声、偏见和 OCR 泄漏？
3. 多模态模型如何评估 grounding、OCR、空间关系、幻觉和多轮视觉对话能力？

## 详细解答与分析

这组题的主线不是背 VLM 名词，而是判断候选人能否把多模态系统拆成一条完整链路：视觉输入如何变成 token，视觉 token 如何进入语言模型，训练数据如何构造，模型错误如何评估，最后如何稳定上线。

**回答结构：**

- 核心机制：先说明图像或视频经过视觉 encoder 得到 patch/token 表示，再通过连接层映射到 LLM 可处理的语义空间。
- 工程取舍：Linear projector 简单高效但表达能力有限；Q-Former 能用 learnable query 控制视觉 token 数量；cross-attention 交互能力更强，但训练和推理成本更高。
- 常见问题：多模态数据容易出现低质量 caption、OCR 泄漏、模板化回答、空间关系错误和幻觉。
- 验证方法：不能只看总分，要拆开看 grounding、OCR、空间关系、细粒度识别、多轮视觉对话、幻觉率和真实任务通过率。

**简洁回答模板：**

我会把多模态大模型看成一条链路：视觉输入 -> 视觉编码 -> token 对齐 -> 指令微调 -> 推理输出 -> 评估反馈。面试时不要只说模型名，要讲清楚为什么选这种连接方式、数据如何保证质量、错误如何定位，以及线上如何控制成本和稳定性。

## 可能追问方向

- 如果 OCR 很强但空间关系很差，如何判断是数据问题、encoder 问题还是连接层问题？
- 长视频输入时视觉 token 数量过大，如何压缩，压缩后会损失什么能力？
- 如果公开 benchmark 分数高，但业务场景幻觉明显，如何重新设计评估集？
- VLM 接到机器人或 VLA 系统时，视觉语言理解如何转成动作决策？
- 多模态模型上线后如何做灰度评估、失败样本回流和二次训练？
