# 每日精选面试题精讲：视频 / 视觉理解

## 面试题目
1. 视频理解中帧采样、temporal token 压缩和 long-context attention 如何取舍？
2. 视频问答如何评估动作理解、事件边界、因果关系和跨镜头一致性？

## 逐题解答
### 题目 1：视频理解中帧采样、temporal token 压缩和 long-context attention 如何取舍？
这题要先说明三者解决的是同一个矛盾：视频信息量很大，但模型上下文、显存和延迟有限。帧采样决定把哪些原始帧送进模型，适合从输入侧降低成本；temporal token 压缩是在特征侧合并冗余时间信息，适合保留长视频全局语义；long-context attention 则尽量保留更多 token，让模型直接建模长程依赖。工程上，短视频动作识别可以用较密采样，长视频问答更依赖关键帧加片段检索；如果任务需要细粒度动作边界，不能压得太狠；如果任务更偏摘要或场景理解，可以更激进压缩。面试里要补评估指标：动作识别准确率、事件边界定位、跨片段一致性、首 token 延迟和单位视频成本。

### 题目 2：视频问答如何评估动作理解、事件边界、因果关系和跨镜头一致性？
视频问答评估不能只看答案是否语义相近，要按能力拆解。动作理解看模型能否区分拿起、放下、打开、关闭等时间相关动作；事件边界看能否定位动作开始和结束，而不是只识别静态画面；因果关系看是否能回答因为前面发生了什么所以后面结果如何；跨镜头一致性看同一人物、物体或状态在多个片段里是否保持一致。数据集设计上要有时间戳标注、干扰帧、相似动作负例和跨片段问题。线上评估还要看幻觉率和不确定性表达：视频里没有出现的信息，模型应该说无法判断，而不是补剧情。
