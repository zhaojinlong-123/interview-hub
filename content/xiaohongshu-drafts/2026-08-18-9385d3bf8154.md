## 逐题解答
### 题目 1：多模态模型推理为什么比纯文本 LLM 更复杂，视觉 encoder 缓存和图像预处理如何优化？

**详细回答：**
多模态推理比纯文本多了图像/视频解码、resize/crop、归一化、vision encoder、视觉 token 压缩和跨模态拼接等阶段。首 token 延迟不仅来自 LLM prefill，还来自视觉预处理和 encoder。优化上，静态图片或重复视频片段可以按媒体哈希缓存视觉特征；多轮对话中同一图片的视觉 token 可复用；图像预处理要批处理并放到 GPU 或高效 CPU pipeline；动态分辨率根据任务选择全局低分辨率加局部 tile，避免所有图片都高分辨率。视频任务可先低帧率粗筛，再对关键片段加密采样。监控要拆分图像下载、预处理、视觉 encoder、projector、LLM prefill 和 decode，否则无法定位瓶颈。

**面试展开：**
如果面试官继续追问，可以把答案落到真实项目：数据从哪里来、如何标注、模型输出什么、低层控制怎么兜底、失败样本如何回流、最终指标如何证明有效。
