## 核心考点

### 1. 视觉 encoder 如何连接 LLM？

简答骨架：视觉 encoder 先把图像切成 patch 或视觉 token，再通过 projector、Q-Former 或 cross-attention adapter 映射到 LLM 可以理解的 token 空间。回答时要比较三种连接方式的成本、表达能力和训练难度。

重点补充：
- Linear projector 简单高效，但压缩能力有限。
- Q-Former 用 learnable query 抽取视觉信息，适合控制 token 数量。
- Cross-attention 交互更强，但推理成本和工程复杂度更高。

### 2. 图文对齐数据如何构造？

简答骨架：先用 caption、OCR、检测框、视觉问答和指令数据构造基础对齐，再用人工筛选、去重、质量打分和负样本控制减少噪声。面试时要说明训练集、验证集和评测集如何隔离，避免答案泄漏。

重点补充：
- 数据不是越多越好，关键是覆盖任务类型和错误模式。
- OCR、空间关系、细粒度属性和多轮对话通常是高价值样本。
- 需要过滤低质量 caption、重复样本、模板化答案和明显幻觉。

### 3. 多模态模型如何评估？

简答骨架：不能只看一个总分，要按能力拆分：OCR、grounding、空间关系、细粒度识别、多轮视觉对话、幻觉率和真实任务通过率。工程上通常结合公开 benchmark、人工评审和线上反馈。

重点补充：
- Grounding 看模型能否把语言回答落到图像区域。
- 幻觉评估要关注“图中没有但模型说有”的内容。
- 线上业务还要看延迟、成本、稳定性和安全边界。
